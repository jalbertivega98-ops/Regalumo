Autores: Xuebin Qin et al., https://github.com/xuebinqin/U-2-Net — licencia Apache-2.0.
Conversión ONNX publicada por el proyecto rembg (https://github.com/danielgatis/rembg, MIT).
SHA-256: 309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8

Se ejecuta en nuestro propio servidor con onnxruntime-node: no se envía ninguna foto a terceros y no tiene coste por uso.
